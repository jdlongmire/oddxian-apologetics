# Source and Attribution Policy

Each BWM-IS volume requires a companion narrative Markdown file before candidate status. The graphic summarizes; the narrative substantiates and qualifies.

1. Scripture is normative theological authority. Verify ESV references and text, distinguish direct quotations from paraphrases, and observe ESV quotation/attribution conditions.
2. Search JD's relevant accessible GitHub repositories for canonical theological and philosophical work; cite repository, path, immutable commit, section or lines. Do not assume a public repository is current canon solely because it is accessible. Cross-check with JD's approved source-of-truth corpus.
3. Seek original external primary material before secondary commentary. Record exact bibliographic locators and accessible links; mark inaccessible originals explicitly and use 'as cited in' where applicable.
4. When interpretations or sources conflict, record the divergence, alternatives, and unresolved status rather than silently arbitrating.
5. Apply confidence labels HIGH (verified primary), MEDIUM (secondary with precise locators), LOW (paraphrase/tertiary), UNCERTAIN (unassessed). Theological classification (direct teaching, necessary consequence, historical formulation, working hypothesis) is a separate field.
6. Each graphic must visibly include 'oddXian.com', ideally in the footer, plus BWM-IS volume ID. The narrative header links to https://oddxian.com until a verified article permalink exists. Do not invent publication URLs. Where an ingested original lacks the visible ID or pointer, never alter the original silently: record the ID in the asset manifest, log the gap in QA-LOG.md, and carry the ID and pointer on the published derivative instead (derivative logged in the QA log). Graphics produced after 2026-11-01 must carry both in the original artwork.
7. Every panel claim maps to the companion narrative and its evidence. Record verified asset hash, original source, revision and approval in the manifest. No publication without explicit JD approval.
