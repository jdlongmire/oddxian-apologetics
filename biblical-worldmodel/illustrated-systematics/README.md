# Biblical WorldModel: Illustrated Systematics

**Status:** Program scaffold, awaiting doctrinal and asset validation.  
**Owner and final authority:** J. D. Longmire  
**Canonical repository:** jdlongmire/oddxian-apologetics

A 24-volume, ten-panel-per-volume illustrated systematic theology, arranged in eight movements. This publication layer does not supersede canonical doctrinal working papers. Consult the source systematic before revising theological claims.

## Structure
- [Series index](SERIES-INDEX.md): volume identifiers, topics and current disposition.
- [Operating agreement](OPERATING-AGREEMENT.md): human and agent responsibilities, controls and handoff.
- [Asset manifest](ASSET-MANIFEST.csv): traceable graphic and script metadata.
- [Panel script template](PANEL-SCRIPT-TEMPLATE.md): repeatable source of truth for each image.

## Publication workflow
proposed → scripted → theological-review → graphic-draft → visual-qa → candidate → JD-approved → published; rejected or superseded are terminal dispositions for individual revisions.

Never label a generated image published or approved merely because it appeared in chat. Original chat images require explicit ingestion, file hash, readable text verification, source mapping, and review. The existing volumes 01 and 02 are **drafted in chat, not yet ingested**.

## Visual identity
Ten numbered panels, scholarly illustrated narrator with glasses, white goatee, clean-shaven upper lip, **red shirt** and dark jacket; navy/gold/parchment; symbolic rather than anthropomorphic depictions of divine Persons; verified spelling and verse attribution. Images are derivative educational illustrations, not independent doctrinal authorities.
