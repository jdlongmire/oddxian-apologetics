# Biblical WorldModel: Illustrated Systematics

**Status:** Program active. Scaffold and first assets ingested 2026-11-01; JD approved thinx-muse as Principal Assistant for this program on 2026-11-01 (doctrine and publication remain JD's).  
**Owner and final authority:** J. D. Longmire  
**Canonical repository:** jdlongmire/oddxian-apologetics

A 25-volume, ten-panel-per-volume illustrated systematic theology, arranged in eight movements. This publication layer does not supersede canonical doctrinal working papers. Consult the source systematic before revising theological claims.

## Publication workflow
proposed → scripted → theological-review → graphic-draft → visual-qa → candidate → JD-approved → published; rejected or superseded are terminal dispositions for individual revisions.

Never label a generated image published or approved merely because it appeared in chat. Original chat images require explicit ingestion, file hash, readable text verification, source mapping, and review. Volumes 02 and 03 and the IS-00 frontispiece plates were ingested on 2026-11-01, and volume 04 was built by thinx-muse and ingested the same day; volume 01 remains drafted in chat for this path (a Triune Foundation plate exists in jd-teaching-infographics on main). See ASSET-MANIFEST.csv and QA-LOG.md.

## Visual identity
Ten numbered panels, scholarly illustrated narrator with glasses, white goatee, clean-shaven upper lip; shirt color rotates through the 8-color palette in the [Visual Series Style Guide](style-guide.jpg), which is the governing visual document; navy/gold/parchment; symbolic rather than anthropomorphic depictions of divine Persons; verified spelling and verse attribution. Images are derivative educational illustrations, not independent doctrinal authorities.

## Substantiation and publication
Every volume requires a [companion narrative](NARRATIVE-TEMPLATE.md) following the [source policy](SOURCING-POLICY.md), with internal corpus cross-references and external primary-source research. Every graphic displays **oddXian.com** and its volume ID; a verified publication permalink replaces the site-root pointer when published.
