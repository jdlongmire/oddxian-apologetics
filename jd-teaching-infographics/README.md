# JD Teaching Infographics

Teaching graphics by James (JD) Longmire: single-sheet, ten-panel summaries of the triune loving communion framework, grounded in Scripture with supporting theology and context. Each graphic is a self-contained teaching plate. Read top to bottom; the final panel gives the summary.

The systematic treatment these plates teach from is the triune loving communion work package in this repository: `arguments-frameworks/triune-loving-communion/`.
